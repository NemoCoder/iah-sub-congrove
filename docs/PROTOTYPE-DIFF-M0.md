## ★「议题与议程」这个洞值得单独记★

它**不是 M0 弄丢的** —— 查 `gitea/dev:web/src/meeting-new.tsx`，改名前也没有。
表单的提交体里一直写着 `agenda: v.agenda ?? ''`、TS 类型里也声明了 `agenda?: string`，
**就是没有 `Form.Item`** —— 于是它永远送空串，后端那一列永远是空。

★为什么所有机械门禁都照不出它★：
- `tsc` 看不见 —— 类型是对的，`v.agenda` 只是永远 undefined；
- `cargo test` / PREPARE 看不见 —— 后端字段与 SQL 都正常；
- ★E2E 也看不见★ —— 测试自己在 `data` 里塞 `agenda`，走的是 API 不是表单。

**一个「字段声明了却接不到输入」的洞，只有对着原型看才照得出来。**
这条正是「机器闸盖不住的那一类」的教科书例子。
